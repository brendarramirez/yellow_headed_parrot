### Lead author Brenda Ramirez (brendarosaramirez@gmail.com)

### Data Processing
- [SNP calling markdown](https://github.com/brendarramirez/yellow_headed_parrot/blob/main/amazona.oratrix.snp.calling.md): Calling SNPs from our Yellow-headed Parrot Ultra Conserved Element (UCE) sequences
- [SNP filtering markdown](https://brendarramirez.github.io/yellow_headed_parrot/amazona_oratrix_snp_filtering.html): Filtering called SNPs to remove outliers and low quality data. Includes code for both PCAs (all filtered samples & eastern Mexico subset) and the SplitsTree of all filtered samples

### Locator
- [Locator markdown](https://brendarramirez.github.io/yellow_headed_parrot/amazona_oratrix_locator.html): Predicting localities of Yellow-headed Parrots of unknown origin
